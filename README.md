# ☕ Coffee Machine Simulator

A **Java-based Coffee Machine Simulator** that models the functionality of a real coffee machine. Users can choose between **espresso, cappuccino, and latte**, while the machine manages ingredients, cups, and money.

The project was built to practice and strengthen fundamental **Object-Oriented Programming (OOP)** concepts in Java, including classes, objects, attributes, methods, loops, and conditional statements.

### ✨ Features

* ☕ Prepare **Espresso, Cappuccino, and Latte**
* 🥛 Manage coffee ingredients such as coffee, milk, sugar, and cups
* 💰 Track and process money
* 📦 Monitor available resources
* ⚠️ Notify the user when resources are insufficient
* 🔄 Interactive machine menu

### 🛠️ Technologies

* **Java**
* **Object-Oriented Programming (OOP)**

### 🎯 Learning Objectives

This project was developed as a practical exercise to improve Java programming skills and help me gain hands-on experience with OOP concepts, methods, loops, conditions, and basic state management.
